# 纸带钢琴工坊

将 MIDI 乐曲转换为机械纸带钢琴的打孔数据，提供从编曲、试听到上机打孔的一体化工具链。

目标机器是一台机械纸带钢琴：双排键盘（上排和弦、下排主旋律）每档 8 个白键（简化键盘槽位 15 格、每排 17 条滚轮轨），纸带自下而上走带，孔位经过滚轮触发拨片发声。换挡键孔（◀◀/▶▶）可移动键盘音域窗口（每按一次 ±1 档 = 一个八度），8 个档位 A0→A1→A2→A3→A4→A5→A6→C7 合起来覆盖钢琴全音域 A0..C8。

## 快速开始

1. **打开工作室**：双击 `perfect-piano/index.html`（推荐 Chrome / Edge，零安装零依赖）。
2. **导入乐曲**：点击「导入 MIDI」选择 `.mid` 文件，或使用「示例曲」直接体验。
   - 多轨文件默认按音域均值自动分配：最高轨 → 主旋律（下排），其余轨 → 和弦（上排）。
   - 单轨文件默认开启「按音高拆分」，低于 C4 的音自动归入和弦排。
3. **预览试听**：播放模拟真实纸带机行为（含换挡时序、双排 105mm 站间错位）。
4. **导出图纸**：导出 1:1 SVG / PNG 用于参考，或保存工程 JSON 后续编辑。

## MIDI 转换管线

- 音高按原音精确落轨（不做移调）：白键/黑键各占自己的槽位，虚拟黑键位（B-C、E-F 处）占位不发声
- 超出当前档位窗口时自动调度换挡键孔：基于真实时间提前量（400ms 换挡 + 200ms 余量）
- 密集音符物理无法打孔时（同轨孔心距 < 4.0mm）自动整曲拉长每拍毫米数，节奏零失真
- 同拍双排孔在带长方向相距 105mm（两排滚轮的物理站间距）

## 打孔机

网页端「打孔机」面板通过 Web Serial（115200）控制 Arduino Nano 固件，完成自动打孔：

- **固件**：`puncher/firmware/puncher/puncher.ino`（Arduino Nano + 2×THB6128 + PWM 舵机）
  - X 轴：Φ24mm 滚轮走带（339.53 脉冲/mm）；Y 轴：1模21齿齿轮齿条（388.03 脉冲/mm）
  - 梯形加减速脉冲引擎、打孔状态机（下压 45° → 钻孔 2s → 抬起 90°）
  - ASCII 行协议：`V/O/J/P/Z0/Z1/F/C/Q/R`；EEPROM 保存标定当量；急停与预留限位
- **上位机**：工作室内打孔面板——点动对刀、设原点、当量校准、逐孔 ACK 流控、暂停/急停、`.punch` 任务文件导出

使用流程：连接 → 点动对刀 → 设为原点 → 生成任务 → 开始打孔。

详细设计见 [打孔机-设计方案.md](打孔机-设计方案.md)。

## 自测

浏览器打开 `perfect-piano/test.html`，覆盖槽位模型、档位表、轨位几何、换挡调度、最密间隔拉长、端到端转换、打孔任务生成等 174 项断言。

## 硬件规格摘要

| 项 | 值 |
|---|---|
| 纸带宽 | 150mm |
| 档位宽 | 130mm（N=8 白键，白:黑 = 7:6） |
| 每排轨数 | 17（◀◀ + 15 槽位 + ▶▶），槽栅距 8.622mm，上下排错开 D=4.311mm |
| 每拍走带 | 9mm（默认，密集曲自动拉长） |
| 两排站间距 | 105mm（沿走带方向） |
| 换挡 | 整档键 ±1 挡（= 一个八度），耗时 400ms，提前量 600ms，曲首连按 3 次 ◀◀ 钉底 A0 |
| 最小孔距 | 4.0mm（任意两孔孔心距 ⟺ 孔缘间距 1.5mm） |
